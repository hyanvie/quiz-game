# Quiz Game 问答小游戏

Web开发技术课程作业 —— 使用原生 HTML / CSS / JavaScript 实现的问答小游戏。

## 功能

- 三屏切换：开始页 → 答题页 → 结果页
- 每题 4 个选项，点击后立即显示对错反馈（正确变绿、错误变红）
- 顶部进度条随答题进度更新
- 实时显示当前题号和得分
- 答完根据得分给出不同的结果评价
- 可以点击 Restart Quiz 重新开始

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript（DOM 操作、事件绑定、setTimeout）

## 本地运行

直接用浏览器打开 `index.html`，或用 VS Code 的 Live Server 插件打开。
